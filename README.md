# Clinavat

**Clinavat**（CLI in a vat）是一个多人共用的网页版 AI 编程工作台。它在服务器上运行官方的 Claude Code 和 Codex CLI，让团队成员在浏览器里与智能体对话，而代码的构建、测试和命令执行发生在每个人自己的开发机上。

- **使用官方 CLI**：不做 API 转换，智能体就是原版的 Claude Code / Codex，会话可以随时恢复。
- **账号集中管理**：管理员登录若干个 CLI 账号（称为“槽位”），再分配给成员使用。
- **代码留在开发机**：服务器上只保存一份同步副本，命令通过 SSH 回到开发机执行。

## 工作原理

```text
 浏览器 ──HTTPS──▶ Web 入口（Caddy / Nginx）──▶ Hub（后端）
                                                 │ 启动官方 CLI
                                                 ▼
                              Claude Code / Codex（使用槽位中的账号）
                                │ 读写源码           │ 执行命令
                                ▼                    ▼
                         项目镜像（服务器）  ◀─Mutagen─▶  开发机（SSH）
```

1. 用户在网页发送消息，Hub 用对话所选槽位的账号启动官方 CLI。
2. CLI 在服务器上的**项目镜像**里读取和修改源码；镜像由 Mutagen 与开发机上的真实目录双向同步。
3. CLI 需要执行构建、测试、Git 等命令时，命令经 `remote-shell` 转发到开发机执行。执行前后都会等待同步完成，保证两边文件一致。
4. 输出通过 SSE 实时推送到网页；需要用户确认的操作会在网页上弹出审批。

管理员还可以使用**本机开发机**：直接打开服务器上的目录，不经过 SSH 和同步。

### 术语

| 术语 | 含义 |
| --- | --- |
| 号池机 | 运行 Clinavat 和官方 CLI 的服务器 |
| Hub | Clinavat 的后端服务（Fastify + SQLite） |
| 槽位 | 一个已登录的 Claude Code 或 Codex 账号；每个槽位只对应一种 CLI |
| 开发机 | 实际存放代码、执行命令的机器，通过 SSH 连接；也可以是号池机本机 |
| 项目 | 开发机上的一个代码目录 |
| 项目镜像 | 号池机上该目录的同步副本，CLI 直接在这里读写文件 |
| 对话 | 一次与智能体的会话，对应一个官方 CLI 原生会话 |

## 主要功能

- **账号与权限**：首次访问时创建管理员；管理员创建成员并分配槽位。登录使用 HttpOnly Cookie，并有来源校验和登录限流。同一槽位同一时间只能被一位用户使用，同一用户可以同时开多个对话。
- **开发机**：每个用户有独立的 SSH 密钥（加密保存），支持导入私钥、跳板机、主机指纹校验。
- **对话**：流式输出、工具调用卡片、网页审批、暂停 / 继续 / 停止，服务重启后可恢复；每个对话可以单独选择槽位、模型、思考强度和权限模式。
- **原生交互**：Plan 模式、规划提问、`/` 命令、`@` 引用文件、Codex Goal、上下文压缩。
- **工作台**：文件预览、Git 状态与 Diff、网页终端（xterm.js）、账号额度显示、对话大纲导航，适配手机。
- **管理面板**：用户、槽位、开发机、站点外观与登录页定制、公开访问地址、上游网关。

## 快速开始

需要 Linux、Node.js 22.13+，以及[部署文档](docs/deployment.md#环境要求)列出的系统工具和官方 CLI。

```bash
cp .env.example .env
openssl rand -hex 32        # 把输出填入 .env 的 CLINAVAT_MASTER_KEY，并妥善保存
npm ci
npm run dev
```

打开 `http://localhost:5173`，创建管理员账号（密码至少 12 位）。接下来：

1. 在「管理面板 → 槽位管理」创建槽位，并按页面提示登录官方 CLI，详见[账号与槽位](docs/accounts.md)。
2. 添加开发机并创建项目，详见[开发机与项目](docs/projects.md)。
3. 在项目中新建对话，开始使用，详见[与智能体对话](docs/agents.md)。

不想安装也可以先体验[在线预览](docs/development.md#在线预览)：它使用同一份前端和模拟数据，可托管在 GitHub Pages 上。

## 安全边界

每个用户拥有独立的 HOME 目录和路径校验，但所有用户的 CLI 都以同一个系统用户运行，没有独立的 Linux 用户、容器或网络隔离。**Clinavat 适合互相信任的团队**；面向不受信任的用户开放前，需要额外加上操作系统级隔离。

多人共用订阅账号须遵守提供方的服务条款。本项目无法保证网络出口或原生 CLI 能避免账号风控。
